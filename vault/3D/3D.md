# 3D

From a cube on a plane to lit, animated worlds. #3d

## The recipe

A 3D scene needs a **camera**, a **light** and **something to see**:

```rust
use bevy::prelude::*;

fn main() {
    App::new()
        .add_plugins(DefaultPlugins)
        .add_systems(Startup, setup)
        .run();
}

fn setup(
    mut commands: Commands,
    mut meshes: ResMut<Assets<Mesh>>,
    mut materials: ResMut<Assets<StandardMaterial>>,
) {
    // The thing.
    commands.spawn((
        Mesh3d(meshes.add(Cuboid::new(1.0, 1.0, 1.0))),
        MeshMaterial3d(materials.add(Color::srgb(0.3, 0.5, 0.9))),
    ));
    // The light.
    commands.spawn((
        PointLight { shadow_maps_enabled: true, ..default() },
        Transform::from_xyz(3.0, 5.0, 3.0),
    ));
    // The eye.
    commands.spawn((
        Camera3d::default(),
        Transform::from_xyz(-2.5, 3.0, 5.0).looking_at(Vec3::ZERO, Vec3::Y),
    ));
}
```

Forget the light and the cube is black. Forget the camera and the screen is empty.

## Build your own: a voxel model

A *voxel* is a little cube on a grid, the 3D cousin of a pixel. Press the **box** button above this preview to build a model of your own, layer by layer, 8 × 8 × 8. It is saved, and it turns up in other examples too: as the rocks in Dodge ([[Make a game]]) and the guard in [[Game AI]].

The preview draws it with sprites, one cube picture per cell, the way old isometric games did: further cubes first, so nearer ones cover them. Click it to turn it.

```rust example=voxels
use bevy::prelude::*;

/// The model: a colour for each filled cell, `x` and `y` across, `z` up.
#[derive(Resource)]
struct Voxels(Vec<(IVec3, Color)>);

/// One cube, white with shaded sides: tinted, it draws any colour.
#[derive(Resource)]
struct Cube(Handle<Image>);

#[derive(Component)]
struct Block;

fn build(
    voxels: Res<Voxels>,
    cube: Res<Cube>,
    blocks: Query<Entity, With<Block>>,
    mut commands: Commands,
) {
    if !voxels.is_changed() {
        return;
    }
    for block in &blocks {
        commands.entity(block).despawn();
    }
    // Further cubes first, lower ones first: each is drawn over those before it.
    let mut cells = voxels.0.clone();
    cells.sort_by_key(|(at, _)| (at.x + at.y, at.z));
    for (order, (at, color)) in cells.into_iter().enumerate() {
        // `x` goes right and down the screen, `y` left and down, `z` up.
        let x = (at.x - at.y) as f32 * 8.0;
        let y = -(at.x + at.y) as f32 * 4.0 + at.z as f32 * 8.0;
        commands.spawn((
            Block,
            Sprite {
                image: cube.0.clone(),
                color,
                custom_size: Some(Vec2::splat(16.0)),
                ..default()
            },
            Transform::from_xyz(x, y + 8.0, order as f32 / 16.0),
        ));
    }
}

fn turn(_click: On<PointerClick>, mut voxels: ResMut<Voxels>) {
    // A quarter turn about the middle: (x, y) becomes (y, 7 - x).
    for (at, _) in &mut voxels.0 {
        *at = IVec3::new(at.y, 7 - at.x, at.z);
    }
}
```

In a real 3D game each cell would be a `Mesh3d` cuboid ([[Meshes and materials]]), and the camera would do the drawing.

## Good to know

- **Units.** One unit is whatever you decide. Physics engines like **metres**; a human is about 1.8 units.
- **Axes.** Right-handed, y up; -z is "forward" for cameras and lights.
- **Everything is PBR.** Materials follow physical rules (roughness, metalness). See [[Meshes and materials]].
- **Scenes in code or data.** Hand-written with [[Scenes and BSN]], or a whole level exported from a tool as glTF.
