# 3D

From a cube on a plane to lit, animated worlds. #3d #beginner

## The recipe

A 3D scene needs a **camera**, a **light** and **something to see**:

```rust
use bevy::prelude::*;

fn main() {
    App::new()
        .add_plugins(DefaultPlugins)
        .add_systems(Startup, setup)
        .run();
}

fn setup(
    mut commands: Commands,
    mut meshes: ResMut<Assets<Mesh>>,
    mut materials: ResMut<Assets<StandardMaterial>>,
) {
    // The thing.
    commands.spawn((
        Mesh3d(meshes.add(Cuboid::new(1.0, 1.0, 1.0))),
        MeshMaterial3d(materials.add(Color::srgb(0.3, 0.5, 0.9))),
    ));
    // The light.
    commands.spawn((
        PointLight { shadow_maps_enabled: true, ..default() },
        Transform::from_xyz(3.0, 5.0, 3.0),
    ));
    // The eye.
    commands.spawn((
        Camera3d::default(),
        Transform::from_xyz(-2.5, 3.0, 5.0).looking_at(Vec3::ZERO, Vec3::Y),
    ));
}
```

Forget the light and the cube is black. Forget the camera and the screen is empty.

## Good to know

- **Units.** One unit is whatever you decide. Physics engines like **metres**; a human is about 1.8 units.
- **Axes.** Right-handed, y up; -z is "forward" for cameras and lights.
- **Everything is PBR.** Materials follow physical rules (roughness, metalness). See [[Meshes and materials]].
- **Scenes in code or data.** Hand-written with [[Scenes and BSN]], or a whole level exported from a tool as glTF.
