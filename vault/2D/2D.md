# 2D

Everything to make a 2D game: pictures, animation, levels, text and movement. #2d

## The recipe

A 2D game needs three things: a **camera**, **things to draw**, and **systems that change them**.

```rust
use bevy::prelude::*;

fn main() {
    App::new()
        .add_plugins(DefaultPlugins.set(ImagePlugin::default_nearest())) // crisp pixels
        .add_systems(Startup, setup)
        .run();
}

fn setup(mut commands: Commands, asset_server: Res<AssetServer>) {
    commands.spawn(Camera2d);
    commands.spawn(Sprite::from_image(asset_server.load("hero.png")));
}
```

## Good to know

- **Units.** One world unit is one pixel at normal zoom. A 16×16 sprite is 16 units wide.
- **Origin.** (0, 0) is the middle of the screen; +y is up.
- **Order.** Sprites with a bigger `z` in their `Transform` are in front ([[Transforms]]).
- **Pixel art.** Use `ImagePlugin::default_nearest()` so scaled-up sprites stay sharp.
