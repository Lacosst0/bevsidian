# bevy_cobweb_ui

A UI and asset-management framework with its own scene format (COB), localisation, widgets and hot reload. #lib #ui

> [!WARNING]
> **No longer maintained** (the README says so as of 2026-01-13); the last release `0.22` targets Bevy 0.17.

## Use instead

| Need | Use |
|:--|:--|
| a reload-while-running UI | [[bevy_hui]] (released for 0.20) |
| compact UI trees | `bsn!` ([[Scenes and BSN]]) |
| ready widgets and themes | Feathers ([[Theming]]) |
| responsive layouts | [[bevy_lunex]] |
