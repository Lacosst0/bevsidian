# Welcome to Bevsidian

**Bevsidian** collects Bevy's documentation into one *linked* vault: the book, the examples, the API docs and community guides as **notes** you can browse like an Obsidian vault. #bevy #beginner

> [!TIP]
> Drag across paragraphs to select text and press `Ctrl+C` (or `Cmd+C`) to copy it.
> Double-click selects a word; triple-click selects a whole block.

## Start here

1. [[ECS]]: entities, components, systems and resources.
2. [[Scenes and BSN]]: describe entity hierarchies with the `bsn!` macro.
3. [[Rendering]]: cameras, meshes, materials and UI.

## How links work

- `[[Note name]]` links to another note, for example [[ECS]] or [[Rendering#Cameras|cameras]].
- A `#tag` such as #beginner groups notes; click one to filter the file list.
- Every note lists its **backlinks** in the sidebar, under Links, and the **Graph** view shows how notes connect.

## Keyboard shortcuts

| Shortcut | Action |
|:--|:--|
| `Ctrl+O` | Quick switcher |
| `Ctrl+G` | Toggle graph view |
| `Alt+←` / `Alt+→` | Back / forward |
| `Ctrl+A` | Select all text in the note |
| `Esc` | Clear selection or close dialogs |
