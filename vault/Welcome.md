# Welcome to Bevsidian

**Bevsidian** collects Bevy's documentation into one *linked* vault: the book, the examples, the API docs and community guides as **notes** you can browse like an Obsidian vault. #bevy #beginner

> [!TIP]
> Drag across paragraphs to select text and press `Ctrl+C` (or `Cmd+C`) to copy it.
> Double-click selects a word; triple-click selects a whole block.

## Start here

Everything about making a game with Bevy 0.20 lives around one hub: **[[Bevy]]**. Open the graph (`Ctrl+G`) to see it: Bevy in the middle, one cluster per area around it.

1. [[Bevy]]: the map of all areas.
2. [[Your first game]]: the fastest path to something playable.
3. [[ECS]]: the heart of Bevy.
4. [[Libraries]]: the best crates, and which work with 0.20 today.

Or pick a path: [[Getting started]], [[Understanding ECS]], [[A 2D game]], [[A 3D game]], [[Multiplayer]], [[Building UI]], [[Make it look good]], [[Ship it]]. In the graph, solid lines are the main route, dashed ones optional steps and dotted ones extras.

## How links work

- `[[Note name]]` links to another note, for example [[ECS]] or [[Rendering#Cameras|cameras]].
- A `#tag` such as #beginner groups notes; click one to filter the file list.
- `` [`Commands`] `` links to Bevy's API docs on docs.rs, like rustdoc: [`Commands`], [`Commands::spawn`], [`bsn!`].
- The link button next to a note's title lists its **backlinks** and outgoing links, and the **Graph** view shows how notes connect.
